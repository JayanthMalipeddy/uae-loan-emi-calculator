# UAE Loan EMI Calculator

Streamlit app to calculate EMI for **Personal, Home and Auto loans** with sliders and a month-wise amortization table.

UAE default tenures (when "Use UAE default tenure" is ticked): Personal 48 months, Auto 60 months, Home 300 months (25 years).

## Run
```bash
uv sync
uv run streamlit run app.py
```

## Test
```bash
uv run pytest -q
```
